This is an example website stemming from a workshop I led on ["your online academic presence"](https://jpeelle.github.io/online-academic-presence/docs/online-academic-presence.html#/title-slide) to show what can be done on GitHub pages. It uses the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and is hosted on GitHub pages. My primary website is <http://jonathanpeelle.net>.

The short version is that every academic should have:

1. A personal website
2. An updated LinkedIn profile
3. A Google Scholar page (once you have more than 0 publications)


For more discussion of scientific communication and social media, you can listen to a [podcast on science communication](https://www.juiceandsqueeze.net/36) Julia Strand and I recorded several years ago that still feels relevant.
